A status cell changes only under this page. The model may propose a class. A second script, with no model, accepts or rejects that proposal. Both results are published.

Allowlist

The checker fetches only the URLs in data/allowlist.json, plus a URL that is already stored on a matrix row once one is added there. It does not open email, a logged-in court system, or the EPS account.

Classes

  1. no_public_action. Every fetched hash matches the stored snapshot, or this is the first snapshot. Status becomes “No public source — checked [date]”. Sectors that already cite a source are left as they are.
  2. source_confirmed_action. The fetched text contains a verbatim quote of the requested act: an inventory cell change, a UIPA release, a bill, an article, or board minutes. The status quotes that span and links the URL.
  3. unsupported_assertion. The fetched text asserts a fact, the quote is verbatim, and contradicts is a verbatim span of the inventory extract or the judgment table already on this site. The label is “Not supported by the primary record”. This protocol does not use “false” or “fraud”.
  4. delegation_without_record. The quote names another office or person as the actor and the same fetched text does not contain the requested permit, invoice, or docket record. A referral that is followed by the record is source-confirmed action.
  5. pending. The fetch failed, the quote is not in the fetched text, the URL is off the allowlist, the class is unknown, or the model output is not JSON. Pending is shown on the matrix page. It does not change a sector status.

Gate

  • The class must be one of the five names above.
  • The sector, when set, must be one of the six matrix ids.
  • Except for no_public_action, the URL must be on the allowlist.
  • Except for no_public_action, the quote must be a character-for-character substring of the fetched text.
  • unsupported_assertion also requires contradicts to be a substring of the committed inventory extract or matrix file.

What is published after every run

  • data/agent-log.jsonl — time, model id, prompt hash, input hash, raw proposal, gate result.
  • prompts/proposal.txt — the prompt text.
  • data/snapshots.json — SHA-256 of each fetched file.
  • data/pending.json — rejected or ambiguous proposals.
  • data/changelog.json — one line per run.

The model is Grok 4.7 through the xAI API when XAI_API_KEY is present in the GitHub Actions secret. The key is not in this repository and not in the browser bundle. If the key is absent, a byte-for-byte unchanged allowlist still records no_public_action. A changed file without a key is pending.

Production is the main branch of this repository, built by Vite and served by Vercel from apps/web. The printed path remains /verify.html.

Mail to the address on the letter is not a class by itself. It can be posted only when the attachment is already a public document with a URL on the allowlist.
