Cab inspection checklist

The letter’s one-sentence request, which any owner or journalist can send today:

Please state in writing the current posted HIOSH operating-permit expiration date and the most recent state safety-inspection date for both passenger elevators at Marine Surf Waikiki, 364 Seaside Avenue, Honolulu, HI 96815 (HAW #67-127 and HAW #67-120).
  • Look inside each cab for the posted operating permit. A permit that can be checked shows the State ID, an expiration date that has not passed, and the inspection authority.
